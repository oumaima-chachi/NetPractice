# NetPractice

## Description
NetPractice is a practical project designed to introduce the fundamentals of computer networking.
The goal of this project is to understand how network communication works by configuring
IP addresses, subnet masks, default gateways, and routing between different devices.

Through a web-based training interface, the project provides multiple network scenarios
that must be fixed to make the network functional.

## Instructions

### Requirements
- A modern web browser (Google Chrome or any Chromium-based browser is recommended)
- Firefox is not recommended due to security restrictions

### How to run the project
1. Download the files attached to the project page
2. Extract the files into a directory of your choice
3. Open the `index.html` file in your web browser
4. Enter your login in the interface
5. Complete the 10 available levels by fixing the network configurations
6. After completing each level, click on **"Get my config"** to export the configuration file

### Submission
- You must export **one configuration file per level**
- A total of **10 configuration files** must be submitted
- All exported files must be placed at the **root of the Git repository**
